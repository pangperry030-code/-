# 在答案出现以前｜遵义会议历史情境数字展

一个面向公众的遵义会议补充性数字传播项目。作品不采用“长页面逐屏翻页”的 PPT 式结构，而是把七座可自主探索的“数字会址”展厅、革命文物特展、权威档案馆和光明终章组织成同一路径内的四幕体验。观众点击章节按钮时，页面在原站点中直接切换场景，不再跳转到新的网址。

## 七个交互展厅

- **前夜·路线**：沿六个关键节点理解危局如何走到遵义。
- **在场·群像**：按身份分组认识公开党史资料确认的20位出席与列席人员。
- **会场·长桌**：点击长桌封签，查看时间、议题、讨论方法、重要决定与会后进程。
- **文献·决议**：从会议议题、组织决定、决议起草到历史评价，理解文献如何形成。
- **实践·检验**：沿会后领导调整、四渡赤水和渡过金沙江观察会议成果如何经受实践检验。
- **精神·灯塔**：交互点亮“坚定信念、坚持真理、独立自主、团结统一”。
- **今日·会址**：以新华社图片建立建筑、会场、展陈与当代参观的现场联系。

## 交互方式

- **便签内深读**：每个被点击的节点、人员组、会议记录、文献层或观察点，都拥有自己的纵向详细介绍；内容在原便签中滚动阅读，不另行分页。
- **站内场景切换**：从数字会址进入文物、档案与终章时，界面在同一路径中整幕变化，不打开新页面。
- **革命文物特展**：八件馆藏文物以馆藏抽屉、检视光镜、影像胶卷、档案签和历史时间轴展开，图文资料来自项目组提供的遵义会议纪念馆官方微信公众号节选。
- **独立权威档案馆**：档案不再占用数字会址栏目，而在文物之后集中呈现中央历史决议、中央党史资料和权威媒体报道；每项资料仍可在当前档案签内纵向深读。
- **光明终章**：以明亮朱红、金色放射光和“坚定信念、坚持真理、独立自主、团结统一”收束参观动线。
- **叙事光线**：七个展厅的右侧背景与左侧数字会址栏目同步从近黑勃艮第红过渡到明亮朱红，并在终章达到最明亮的色彩状态。
- **公开扫码分享**：各章节右下角均可打开红金二维码，现场扫码进入公开网站，也可下载高清二维码海报。
- **自主参观**：展厅没有强制逐页顺序，左侧数字会址地图和前后按钮都可直接切换空间。

## 内容原则

- 历史结论、时间节点和会议内容均依据公开权威资料。
- 路线与会场交互仅用于梳理关系，不替代专业地图和原始档案。
- 不虚构历史人物对白、声音和心理活动。
- 不设置改写历史、阵营选择或“如果历史重来”等历史假设。
- 文物页面严格标注文物名称、年代、材质、登记号、级别和尺寸，并区分1934—1935年革命文物与1954年纪念物。
- 新闻图片逐项标注来源；封面只增强原照片中吊灯的光效，不把视觉处理当作文物信息。

## 本地运行

    pnpm dev
