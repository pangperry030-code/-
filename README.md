# 在答案出现以前｜遵义会议历史情境数字展

一个面向公众的遵义会议补充性数字传播项目。作品不采用“长页面逐屏翻页”的 PPT 式结构，而是把网站设计为一座可自主探索的“数字会址”：观众可以选择展厅、点击历史节点、打开会议记录、梳理转折机制、点亮精神坐标，并从权威史料柜核验内容来源。

## 八个交互展厅

- **前夜·路线**：沿六个关键节点理解危局如何走到遵义。
- **在场·群像**：按身份分组认识公开党史资料确认的20位出席与列席人员。
- **会场·长桌**：点击长桌封签，查看时间、议题、讨论方法、重要决定与会后进程。
- **文献·决议**：从会议议题、组织决定、决议起草到历史评价，理解文献如何形成。
- **实践·检验**：沿会后领导调整、四渡赤水和渡过金沙江观察会议成果如何经受实践检验。
- **精神·灯塔**：交互点亮“坚定信念、坚持真理、独立自主、团结统一”。
- **今日·会址**：以新华社图片建立建筑、会场、展陈与当代参观的现场联系。
- **档案·索引**：逐项链接中央历史决议、党史和文献研究资料及权威媒体报道。

## 内容原则

- 历史结论、时间节点和会议内容均依据公开权威资料。
- 路线与会场交互仅用于梳理关系，不替代专业地图和原始档案。
- 不虚构历史人物对白、声音和心理活动。
- 不设置改写历史、阵营选择或“如果历史重来”等历史假设。
- 新闻图片逐项标注来源；封面只增强原照片中吊灯的光效，不把视觉处理当作文物信息。

## 本地运行

    pnpm install
    pnpm dev

默认访问 http://localhost:3000/。
